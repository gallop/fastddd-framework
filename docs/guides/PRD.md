# FastDDD 企业级领域驱动开发框架 PRD 文档

## 1. 产品概述

### 1.1 产品定位
FastDDD 是一款专为 Java Web 开发设计的企业级开发框架，基于领域驱动设计（DDD）模式深度融合 Spring 全家桶技术栈，致力于为开发者提供一套高内聚、强扩展、工程化标准统一的开发平台。

### 1.2 核心理念
框架围绕三大核心理念构建：
- **高标准**：统一代码/架构/文档规范，确保90%+代码一致性
- **高效率**：一键生成完整代码，开发效率提升60%，单表CRUD开发从2天缩短至5分钟
- **高协同**：标准化接口规范，联调时间减少50%

### 1.3 设计愿景
"让所有人写的代码就像出自一人之手" - 通过统一的开发规范和标准化实施方案，实现真正的企业级代码质量管控。

## 2. 核心功能模块

### 2.1 基础架构层

#### 2.1.1 DDD 分层架构
- 严格按照领域驱动设计的分层架构组织代码
- 清晰的分层架构、领域模型驱动、业务表达力强
- 保留 DDD 优势，消除 DDD 痛点
- 简化概念、减少样板代码、标准化实施方案

#### 2.1.2 统一规范体系
- **统一命名规范**：从数据库字段到 Java 属性，自动转换遵循统一标准
- **统一异常体系**：所有组件使用一致的异常处理机制，错误信息清晰明确
- **统一响应格式**：API 返回格式标准化，前端对接零障碍

### 2.2 条件控制系统

#### 2.2.1 环境感知机制
条件控制器(Condition)提供优雅的环境感知机制，划分为三大维度：
- **环境维度**：开发/测试/生产环境
- **系统维度**：Windows/Linux/Mac 平台
- **个人维度**：特定用户权限控制

#### 2.2.2 语义化条件控制
- 语义化命名的Condition类（如OnlyDevRunCondition、OnlyWinRunCondition）
- 通过@Conditional注解精准控制组件加载与运行
- 支持灵活组合多个条件
- 适用于多环境配置管理、跨平台兼容性处理

### 2.3 异常体系设计

#### 2.3.1 企业级异常处理机制
- 构建优雅的企业级异常处理机制
- 统一异常体系设计，确保错误信息的一致性和可追溯性
- 标准化异常分类和处理流程
- 支持异常链路追踪和日志记录

### 2.4 实用工具类体系

### 2.10 前端管理平台

#### 2.10.1 数据库管理模块
- **DDL管理**：自动生成标准化数据库DDL语句，支持字段注释完整性检查
- **字段标准化**：统一的字段命名规范，自动生成符合DDD规范的字段定义
- **主键管理**：自动配置主键自增策略，确保数据库设计的一致性
- **数据源管理**：支持多数据源配置和切换，便于不同环境的数据库管理

#### 2.10.2 字段库管理
- **字段复用**：建立企业级字段库，实现字段定义的标准化和复用
- **字段分类**：按业务域对字段进行分类管理，提升字段查找效率
- **状态管理**：字段启用/禁用状态控制，支持字段生命周期管理
- **类型标准化**：统一的字段类型定义，确保数据类型的一致性

#### 2.10.3 BasePO字段自动生成
- **标准化基础字段**：自动生成createUser、updateUser、createTime、updateTime等标准字段
- **字段自动填充**：支持字段的自动填充策略配置
- **DDD规范集成**：生成的字段完全符合DDD架构规范
- **批量操作**：支持批量生成和更新BasePO字段定义

#### 2.10.4 可视化界面设计
- **响应式布局**：基于Vue.js + Element UI的现代化界面设计
- **模块化导航**：清晰的功能模块划分，支持快速功能定位
- **实时预览**：DDL生成和字段配置的实时预览功能
- **操作便捷性**：一键生成、批量操作、快速配置等便捷功能
