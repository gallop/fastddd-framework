# Security Policy

## Supported versions

FastDDD Framework is currently in the 1.0 pre-release line. No public GA version is supported yet. Supported release lines and end-of-support dates will be published with the first GA release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or generated examples.

Send a private report to `39100782@qq.com` with the subject `[FastDDD Security]`. Include the affected artifact/version, reproduction steps, impact, and any proposed mitigation. Do not include credentials or customer data unless an encrypted transfer method has been agreed first.

The maintainer will acknowledge receipt and coordinate validation and disclosure. Formal response and remediation SLAs will be defined before the first public GA release.
